<h1 align="center">Mind Your Own WhatsApp</h1>

Here is my lil Stuff Chromium extension for keeping your WhatsApp Web chats from being read by random nosy people just glancing over your shoulder.

## What this is

This project was made just for one main reason, privacy. If you’re checking WhatsApp in public, at work, or anywhere, this extension blur out the stuff that shouldn’t be visible at a glance so your chat stays low-key and safe.

Basically, it’s like a tiny privacy shield for your screen—clean, useful, and not trying too hard.

## How to use it

### 1. Clone the project from GitHub

- Open your terminal.
- Run:

```bash
git clone https://github.com/rahmatrians/mind-your-own-whatsapp.git
cd mind-your-own-whatsapp
```

- Or just download the ZIP from the GitHub repository and extract it locally.

### 2. Install the extension

- Open Chrome or any Chromium-based browser.
- Go to the Extensions page.
- Turn on Developer mode.
- Click Load unpacked.
- Pick this project folder that already cloned.
- enjoy the stuff.

### 3. Open WhatsApp Web

Open https://web.whatsapp.com and make sure the extension is active.

### 4. Tune the blur settings

Click the extension icon in the toolbar to open the popup. From there, you can:

- turn protection on or off
- adjust the blur strength
- blur text, images, videos, avatars, and names
- enable reveal-on-hover when you wanna sneak a quick peek

### 5. Use the shortcut

Quick toggle:

- Alt + Shift + B

This is the fastest way to flip the protection on or off when you need to move quick.

## Notes

This extension is built for privacy and screen control, not for messing with WhatsApp’s core behavior or doing anything shady. It’s just a simple browser-side layer that helps keep sensitive stuff out of casual view.

You can also tweak the blur settings in the popup to match your vibe and comfort level.
